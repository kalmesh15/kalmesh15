### 💼 Online Job Finder System

**Tech Stack:** Java, Spring Framework, Spring MVC, Hibernate, JPA, MySQL, JSP

- Developed a web-based job portal application.
- Implemented user registration and profile management.
- Implemented CRUD operations for user profiles.
- Added resume upload and management functionality.
- Used Hibernate and JPA for database operations and entity mapping.
- Implemented layered architecture using Controller, Service and DAO layers.
- Used JSP for the user interface and Spring MVC for request handling.

---

### 🍕 Pizza App Management System

**Tech Stack:** Java, Servlets, JSP, Hibernate, JPA, MySQL

- Developed a web-based pizza management application.
- Implemented CRUD operations for pizza management.
- Added filtering based on pizza price, name and category.
- Integrated Hibernate/JPA with MySQL for persistent data storage.
- Implemented entity relationships between pizzas, employees and preparation records.
- Applied layered architecture using Servlet, Service, DAO, DTO and Entity classes.

### 🔧 Common Module Project

**Tech Stack:** Java, Spring Framework, Spring MVC, Hibernate, JPA, MySQL, JSP

- Developed a common application module for user registration, login,
  profile management and validation.
- Implemented CRUD operations using Spring MVC, Hibernate and JPA.
- Applied layered architecture using Controller, Service, DAO, DTO and Entity classes.
- Implemented form handling and server-side data validation.
- Integrated Hibernate/JPA with MySQL for persistent data storage and entity mapping.
- Implemented REST APIs for validation and login-related operations.
- Implemented email OTP functionality for account verification and
  password reset workflows.
- Used JSP for the frontend and Spring MVC for request handling and form data binding.
- Used Maven and Git/GitHub for dependency management and version control.
